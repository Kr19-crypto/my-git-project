🪑 Agent Review Roundtable

多 Agent 圆桌代码评审 · 报告查看器与行动项回灌

❓ 这是什么？

Agent Review Roundtable 是一个“多 Agent 圆桌代码评审”工具： 它会读取代码变更（git diff / 目录快照 / patch 文件），让 架构师、安全、测试、维护者 等 AI 角色轮流讨论， 最终生成一份结构化评审报告，包含问题、风险、改进建议和可直接执行的下一步行动项。

📥 评审代码用 CLI 或 DSH 对 Git 仓库、非 Git 目录或 diff 文件发起评审。
📋 结构化报告Summary / Blocking / Suggestions / Risks / Action Items 一目了然。
↩️ 行动项回灌把评审结论转成“下一步开发指令”，直接交给开发 Agent 继续处理。

📖 这个页面怎么用？

  1. 先获得一份评审结果 review.json。你可以在项目目录执行：
    node dist/cli.js review --diff-file samples/aurora.patch --yes --output-json samples/aurora.review.json
  2. 点击上方「📂 打开 review.json」选择该文件；没有现成文件时可点击「载入示例」立即体验。
  3. 查看评审结论、必须修复项、改进建议、风险、行动项和圆桌讨论过程。
  4. 把底部「↩️ 回灌到开发会话」中的指令复制，粘贴给开发 Agent 或开发会话，让它按行动项继续修改。

提示：本页面是“评审报告查看器 / 回灌工具”，本身不调用 LLM；生成评审报告请使用 CLI 或 DSH 插件。
